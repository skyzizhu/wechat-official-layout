# 文排 · 微信公众号文章排版工具

「文排」是一款**纯前端**的公众号文章排版工具：把 Markdown 或随手写的普通文本，一键变成可直接粘贴进微信公众号后台的精美排版。无需注册、无需后端，所有内容均在浏览器本地处理。

## ✨ 核心特性

### 统一可视化编辑器
- **单一编辑面（图文同流）**：左侧是一整个连续编辑区——文本段落与图片卡片在同一条文档流中，像写文档一样在图片前后直接打字、回车、粘贴，不再被块边界打断
- **格式纯文本化**：选中文字套用格式（标题/引用/代码/题注）后，左侧纯文本外观保持原样——格式效果只体现在右侧排版预览；结构意图存于段落属性，序列化时注入标记；状态栏「Markdown」开关可只读查看当前生效的排版用源码（与预览/下载 MD 同源）
- **图片直接粘贴 / 拖放 / 本地选取**：截图后直接 ⌘V 贴进编辑器光标处，图片以压缩形式存入本地图片库，正文只留短令牌，不会被 base64 源码淹没；粘贴含图片行的文本会自动拆出内联图片卡
- **1列 / 2列 / 3列画廊**：悬停图片卡片即可切换布局，不足的格子显示「添加图片」占位可后补；序列化为微信最稳定的无边框自适应表格结构
- **题注就地编辑**：每张图片下方直接输入题注（图 1 · 说明文字），预览与复制实时同步
- **安全型卡片（Dark Mode 友好）**：一键将单图转为「拍立得衬底卡片」，白底留白护城河，暗黑模式下图片更耐看

### 智能内容识别与排版引擎
- **双副本内容模型（纯文本优先）**：左侧编辑器永远展示纯文本（用户编辑面），内部另持一份「排版用 markdown」副本（转换源）：
  - 粘贴纯文本 → 智能引擎识别内容意图（表格 / 清单 / 章节 / 问答……）并转为模板格式渲染
  - 粘贴 Markdown → 自动降级为纯文本展示（标题、加粗、行内代码、链接标记溶解；表格 / 代码围栏 / 列表 / 引用保留），预览仍按原始 Markdown 语义保真渲染；一旦编辑纯文本，预览改由智能引擎从纯文本重新推导
  - 「下载 MD」始终导出排版用 Markdown 源文件
- **自动识别输入内容**：无需选择模式，引擎统一按内容意图智能识别（带置信度评分与纠偏提示）
- **纯文本智能排版**：对普通中文长文本进行语义层级解析，自动转换：
  - 标题层级（中文章节「一、」「第X章」、数字编号「1.1」「1.1.1」、括号编号「（一）」等 → H2~H5）
  - 有序 / 无序列表（`•` `◆` `①` `1、` 等多种符号）、条目标题自动加粗强调
  - 表格（半角/全角管道符、Tab 制表符、多空格对齐均可识别）
  - 代码块（自动推断 JavaScript / TypeScript / Python / SQL / Shell 等语言，支持无围栏缩进代码与跨空行合并）
  - Q&A 问答访谈、「导读 / 注意 / 提示」等 Callout、金句候选（低置信度提示条一键确认）
  - 图片与题注、参考文献条目、裸链接转可读链接、中英文盘古之白
- **识别纠偏**：低置信度决策以悬浮提示条呈现，一键「转为金句 / 改为代码块 / 保留」，改错随时可撤销

- **智能主色搭配**：任选一个主色，自动生成和谐配色并重排标题、引用块、荧光笔高亮等全套色彩
- **字号微调**：14px 紧凑 / 15px 微信推荐 / 16px 醒目

### 便捷导出与发布
- **一键复制富文本**：复制带完整内联样式的富文本，粘贴进公众号后台即所见即所得（外链自动转文末脚注）
- **导出高清长图**：2x 像素密度 PNG 长图
- **本地自动保存**：草稿与偏好 500ms 防抖暂存 LocalStorage，⌘S 随时手动保存
- **编辑 / 预览滚动同步**：桌面端滚动左侧编辑区，右侧预览按比例联动

### ⌨️ 键盘快捷键
| 快捷键 | 功能 |
|---|---|
| ⌘B / ⌘I | 选中文本加粗 / 斜体（再按一次取消） |
| ⌘1 / ⌘2 / ⌘3 | 选中行转一 / 二 / 三级标题 |
| ⌘S | 立即保存草稿 |

## 🚀 快速开始

```bash
# 安装依赖（需 Node.js 20+）
npm install

# 启动开发服务器
npm run dev

# 生产构建（静态导出到 out/）
npm run build
```

打开 [http://localhost:3000](http://localhost:3000) 即可使用。

发布流程：粘贴内容 → 选择主题与主色 → 点击「复制富文本」→ 到微信公众号后台粘贴发布。

## 🧪 测试

三层回归测试网，覆盖智能解析引擎与编辑器分块模型：

```bash
node tests/run-golden.mjs     # 输出快照回归（25 例，--update 重新生成基线）
node tests/run-complex.mjs    # 复杂场景冒烟（60 场景：图文/编号/表格/代码/边界）
node tests/run-legacy.mjs     # 遗留草稿损坏自愈审计（16 形态）
node tests/run-wechat.mjs     # 微信合规校验（规范 2.1/2.2/2.3 断言）
node tests/run-dual.mjs       # 双副本模型校验（降级溶解/往返还原/语义保真）
```

## 📦 部署

静态化输出（`output: 'export'`），不依赖服务器 Node 运行时。完整部署指南见 [deploy/README.md](deploy/README.md)（Nginx / Apache 方案、一年期静态资源缓存、Gzip、CentOS 一键脚本 `deploy/centos-deploy.sh`）。

## 🛠️ 技术栈

- [Next.js](https://nextjs.org)（App Router，静态导出）+ React 19 + TypeScript
- Tailwind CSS 4
- react-markdown + remark-gfm + rehype-raw（Markdown 渲染）
- html-to-image（长图导出）
- lucide-react（图标）

## 🔒 隐私说明

排版、图片（本地图片库）、草稿与导出均在浏览器本地完成，文章内容不会上传到任何服务器——没有例外。
