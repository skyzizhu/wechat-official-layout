# 文排 · 微信公众号文章排版工具

「文排」是一款**纯前端**的公众号文章排版工具：把 Markdown 或随手写的普通文本，一键变成可直接粘贴进微信公众号后台的精美排版，无需注册、无需部署后端，所有内容均在浏览器本地处理。

## ✨ 核心特性

### 智能内容识别与排版引擎
- **自动识别输入格式**：自动判断内容是 Markdown 源码还是普通文本（带置信度评分），也可手动切换三种模式（自动 / Markdown / 纯文本）
- **纯文本智能排版**：对普通中文长文本进行语义层级解析，自动转换：
  - 标题层级（中文章节序号「一、」「第X章」、数字编号「1.1」、括号编号「（一）」等 → H2~H4）
  - 列表（`•` `◆` `①` `1、` 等多种符号）、条目标题自动加粗强调
  - 表格（半角/全角管道符、Tab 制表符、多空格对齐均可识别）
  - 代码块（自动推断 JavaScript / Python / SQL / Shell 等语言）
  - Q&A 问答访谈、「导读 / 注意 / 提示」等 Callout 提示块、金句引用
  - 图片链接（`配图：URL`）、图片题注（`▲ 图1：…`）、流程步骤与时间线
  - 参考文献条目、裸链接自动转为可读链接、中英文之间自动加空格（盘古之白）
- **外链转文末脚注**：微信公众号会拦截外部链接，开启后自动把正文外链转成 `<sup>[1]</sup>` 角标，并在文末生成「参考链接」清单（公众号原生链接不受影响）
- **首句设为标题**：可选将第一句话识别提升为文章大标题（默认作为正文首段）

### 16 款高颜值排版主题
公众号风 · 新中式 · 莫兰迪柔调 · 潮流波普 · 暖阳拿铁 · 薄荷柠檬 · 现代简约 · 杂志风 · 商务报告 · 艺术策展 · 文艺清新 · 经典学术 · 复古报纸 · 温暖手帐 · 暗色极客 · 科技未来

- **智能主色搭配**：任选一个主色，自动生成和谐配色并重排标题、引用块、荧光笔高亮等全套色彩
- **字号微调**：14px 紧凑 / 15px 微信推荐 / 16px 醒目，三档黄金字号

### 便捷导出与发布
- **一键复制富文本**：复制带完整内联样式的富文本，直接粘贴进公众号后台即所见即所得
- **导出高清长图**：2x 像素密度 PNG 长图，完整渲染长文、正确处理背景色与居中偏移
- **本地自动保存**：草稿与主题、主色、字号等偏好自动暂存到浏览器 LocalStorage（500ms 防抖），刷新不丢失
- **响应式布局**：桌面端左右分栏实时预览，移动端底部 Tab 切换编辑 / 预览

## 🚀 快速开始

```bash
# 安装依赖（需 Node.js 20+）
npm install

# 启动开发服务器
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000) 即可使用。

发布流程：粘贴内容 → 选择主题与主色 → 点击「复制」→ 到微信公众号后台粘贴发布。

## 🛠️ 技术栈

- [Next.js](https://nextjs.org)（App Router）+ React 19 + TypeScript
- Tailwind CSS 4
- react-markdown + remark-gfm + rehype-raw（Markdown 渲染）
- html-to-image（长图导出）
- lucide-react（图标）

## 📁 项目结构

```
src/
├── app/                  # 页面入口（App Router）
├── components/           # 编辑器、预览、主题选择器、导出工具栏等组件
├── themes/
│   ├── presets/          # 16 款排版主题预设
│   └── types.ts          # 主题类型定义
├── lib/
│   ├── smart-parser.ts   # 纯文本智能排版引擎（格式识别 + 语义解析）
│   ├── link-footnotes.ts # 外链转文末脚注引擎
│   ├── color-harmonics.ts# 智能主色搭配引擎
│   ├── rich-text-serializer.ts # 高保真富文本序列化
│   └── export.ts         # 富文本复制 / PNG 长图导出
└── hooks/                # 通用 Hooks
```

## 🔒 隐私说明

所有排版与导出均在浏览器本地完成，文章内容不会上传到任何服务器。
